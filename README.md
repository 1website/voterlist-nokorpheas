# ប្រព័ន្ធគ្រប់គ្រងអ្នកចុះឈ្មោះបោះឆ្នោត រដ្ឋបាលឃុំនគរភាស
### Nokor Pheas Commune Voter Registration and Election Day Management System
**ស្រុកអង្គរជុំ ខេត្តសៀមរាប (១០ ភូមិ • ១៤ ការិយាល័យបោះឆ្នោត)**

---

## 🌟 លក្ខណៈពិសេសចម្បង (Core Features)

### ១. គ្រប់គ្រងទិន្នន័យភូមិសាស្ត្រ និងការិយាល័យ (Geography & Polling Stations)
- **១០ ភូមិ**: រមៀត, គោកដូង, ទំរាប់, គោកស្ពាន, តាគួយ, ព្រៃទទឹង, ដូនអែម, សំបួរ, ជ្រៃ, ពង្រ (មានព័ត៌មានមេភូមិ, លេខទូរស័ព្ទ, ចំនួនខ្នងផ្ទះ)
- **១៤ ការិយាល័យបោះឆ្នោត** (កូដ ០៧០១ ដល់ ០៧១៤): ទីតាំងជាក់ស្តែង (សាលារៀន, វត្តអារាម), កម្រិតផ្ទុកអតិបរមា, និងមន្ត្រីទទួលខុសត្រូវ
- **ការបែងចែក (Mapping)**: ភ្ជាប់ភូមិទៅកាន់ការិយាល័យបោះឆ្នោតជាក់លាក់

### ២. គ្រប់គ្រងព័ត៌មានអ្នកបោះឆ្នោត (Voter Management)
- **ចុះឈ្មោះ & កែប្រែ**: ឈ្មោះខ្មែរ-ឡាតាំង, ភេទ, ថ្ងៃខែឆ្នាំកំណើត, លេខអត្តសញ្ញាណប័ណ្ណសញ្ជាតិខ្មែរ, អាសយដ្ឋាន, កូដអ្នកបោះឆ្នោត (`NP-0701-0001`), លេខរៀងក្នុងបញ្ជី
- **ផ្ទៀងផ្ទាត់ទិន្នន័យស្ទួន (Anti-Duplicate Check)**: ពិនិត្យលេខអត្តសញ្ញាណប័ណ្ណស្វ័យប្រវត្តិទាំងលើ Client និង Server
- **តាមដានស្ថានភាព**: សកម្ម (Active), បានផ្លាស់ចេញ (Moved), មរណភាព (Deceased), ផ្អាកសិទ្ធិ (Suspended)

### ៣. ស្វែងរក និងផ្ទៀងផ្ទាត់រហ័ស (Search & QR Verification)
- ស្វែងរកពហុលក្ខខណ្ឌ (ឈ្មោះ, លេខអត្តសញ្ញាណប័ណ្ណ, ភូមិ, ការិយាល័យ, ស្ថានភាព)
- **កាមេរ៉ាស្កេន QR Code / Barcode (HTML5-QRCode)**: ស្កេនប័ណ្ណព័ត៌មានអ្នកបោះឆ្នោត បង្ហាញលេខរៀង និងការិយាល័យភ្លាមៗ
- **ប័ណ្ណព័ត៌មានអ្នកបោះឆ្នោត (Printable Voter Card)**: មាន QR Code សម្រាប់បោះពុម្ពទោល ឬជាបាច់ (Batch Print ៤ ប័ណ្ណក្នុង A4 មួយសន្លឹក)

### ៤. តាមដាន និងស្ថិតិថ្ងៃបោះឆ្នោត (Election Day Operations)
- **កត់ត្រាវត្តមាន (1-Click Check-in)** តាមពេលវេលាជាក់ស្តែង ជាមួយសំឡេង Beep បញ្ជាក់
- **ផ្ទាំងគ្រប់គ្រងផ្សាយផ្ទាល់ (Real-Time Live Turnout Dashboard)**: ភាគរយអ្នកបោះឆ្នោតរួច ធៀបនឹងមិនទាន់បោះឆ្នោត, ក្រាហ្វិកតាមការិយាល័យ និងតាមភូមិ

### ៥. របាយការណ៍ និងការទាញយកទិន្នន័យ (Reports & Export)
- **នាំចេញ Excel (.xlsx)**: បញ្ជីឈ្មោះអ្នកបោះឆ្នោតមានទម្រង់ស្តង់ដារ ជាមួយកន្លែងចុះហត្ថលេខា/ផ្តិតមេដៃ
- **បោះពុម្ពបញ្ជីបោះឆ្នោតផ្លូវការ (Official Print View)**: ទម្រង់ គ.ជ.ប សម្រាប់បិទផ្សាយតាមការិយាល័យ
- **របាយការណ៍ស្ថិតិប្រជាសាស្ត្រ**: បែងចែកតាមភេទ និងក្រុមអាយុ (១៨-៣០, ៣១-៤៥, ៤៦-៦០, ៦០+)

### ៦. សុវត្ថិភាព និងការកំណត់សិទ្ធិ (User Roles & Permissions)
- **Admin (មេឃុំ/ស្មៀនឃុំ)**: សិទ្ធិពេញលេញលើប្រព័ន្ធ គ្រប់គ្រងអ្នកប្រើប្រាស់ និងទិន្នន័យទាំងអស់
- **មន្ត្រីការិយាល័យ (១៤ នាក់)**: ស្វែងរក និងកត់ត្រាវត្តមាន Check-in តែក្នុងកម្រិតការិយាល័យរបស់ខ្លួន
- **មេភូមិ (១០ នាក់)**: ពិនិត្យមើលបញ្ជីឈ្មោះអ្នកបោះឆ្នោតក្នុងភូមិរបស់ខ្លួន
